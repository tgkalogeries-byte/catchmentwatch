HOW TO READ THIS

Signals first. Conclusions later.

A gauge outside its usual range can justify checking the source and local context. It does not establish that flooding is occurring. Official Environment Agency alerts remain clearly separate from our own screening cues.

NEXT ANALYTICAL STEP

The next version can backtest rainfall-to-river level changes against archived observations, measure lead time and false alarms, then display an evidence trail for each candidate signal.

DATA LIMITS

Coverage and latency vary.

Feeds update at different rates, some readings are missing, and nearby sensors are not necessarily upstream or in the same catchment. The API is beta and is not a safety-critical service.
